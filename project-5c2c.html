5C2C

Web app · Campus marketplace connecting Claremont Colleges students with paid services

React.js Tailwind CSS Node.js / Express Supabase Socket.io

5C2C is a campus marketplace we built for the Claremont College Consortium, where students can post services, get discovered, and get paid. Nail art, graphic design, music production, hair styling, henna, rides, all in one place instead of scattered across Instagram DMs and group chats. It's live and in use on campus now!

What It Does

Students can create a shop, upload photos of their work, set prices, and manage availability. Buyers browse a card-based feed, filter by category, book appointments, and message sellers directly.

Browse & Search

Search for a service or filter by category, like nails, design, or rides.

Seller Profiles

Each seller has a page with photos of their work, their prices, and their average rating.

Create Listing

Sellers post a service with photos, which upload straight to Supabase Storage.

Booking System

Buyers pick a service, choose a time, and confirm the details.

Real-Time Messaging

Buyers and sellers chat in real time through Socket.io, with markers for unread messages.

Listings and profiles also show reviews and ratings, and signing up takes a .edu email so the marketplace stays within the 5C community.

Designing the Browse Page

My team and I tested a few different design approaches for browsing. When we looked at existing resale and small business platforms, almost all of them used either a Pinterest-style or an Instagram-style layout. We went with Pinterest style, where the cards still sit in a grid but each one is a different height. That offset adds some visual interest, so the feed doesn't look as boring as a uniform grid.

My Role

I worked on the frontend of a React and Tailwind CSS app, with a Node.js/Express backend and Supabase handling sign-in, the PostgreSQL database, and file storage. Here's what I built:

  • Browse/search page, listing cards, and individual listing detail pages
  • Category filters, search bar, and the Pinterest-style layout for browsing services
  • Seller profile pages (portfolio, bio, ratings display) and the buyer-facing booking flow
  • "Create Listing" and "My Listings" management pages, including image upload connected to Supabase Storage
  • Chat interface integrated with the Socket.io real-time layer
  • Protected routes and navigation
  • Connecting frontend components to the backend REST APIs

A P-ai project, co-managed by Arushi Bhandari and Vanisha Kheterpal (both Harvey Mudd '29) and built by a team of 5 to 7 students over a 10-week sprint.
